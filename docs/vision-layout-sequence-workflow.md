# 从视觉检测获取螺栓布局并判断拧紧顺序

现场连接板的螺栓阵列尺寸随节点变化。拟验证的流程由目标检测提供螺栓位置，程序将检测结果概括为布局摘要，文字大模型结合布局、拧紧坐标序列和作业规则判断顺序。布局摘要用几行文字说明这一块板的范围和排列，模型可以沿原始序列直接检查。

## 从检测结果得到布局摘要

1. **取得连接板参考图。** 选一帧能覆盖整块连接板、螺栓位置清晰的画面，使用目标检测模型定位螺栓头，提取检测框中心点。布局需要包含待拧位置，漏检会影响行列数和内层完成的判定。
2. **统一平面坐标。** 斜拍时，可利用板面上可识别的参考点做透视校正。用相对位置判断层级时，可以采用归一化坐标或行列坐标。需要输出毫米尺寸时，再引入尺度标定。
3. **提取布局尺寸。** 对规则阵列，将中心点沿横向和纵向归组，得到行数、列数和坐标范围。传给模型的摘要可以写成「6 行 × 8 列，`x` 向右，`y` 向下，左上为 `(1,1)`，右下为 `(8,6)`」。

## 用布局和坐标序列直接判断

从视频中识别每次拧紧操作的位置，把它转换到布局摘要使用的坐标系。按实际操作时间排列这些坐标，序列中的第 `k` 条就是第 `k` 步。大模型接收这条序列、简短布局摘要和该节点适用的规则，逐步检查当前坐标属于哪一层、进入该层时更内层是否已完成。输出包括合规结论，以及首次违规的步号、坐标和依据。

下面用数据集 `v1.1-0005` 的前五步示例。将原坐标除以 10 后，阵列坐标从 `(1,1)` 到 `(8,8)`，中心在 `(4.5,4.5)`。 [仿真数据集](../data/v1.1/dataset.jsonl)

```text
布局 8 行 × 8 列，x 向右，y 向下，左上为 (1,1)，右下为 (8,8)
操作 (5,5) → (5,4) → (4,4) → (4,5) → (8,2) → …
仿真规则 从中心逐层向外拧，同一层内顺序不限，内层完成后才能进入外层
```

前四个坐标都落在中心的四颗螺栓上。第 5 步的 `(8,2)` 落在最外层，此时第 2、3 层尚未完成，因此第 5 步首次违规。这个例子也说明了两个输入的作用。布局提供判断位置的参照，序列提供判断先后的时间顺序。

## 不规则节点和后续验证

缺位或不规则的节点仍可用目标检测获取位置分布。布局摘要可按该节点的作业规则补充分区边界或各层应拧数量。实时检查时，各层应拧数量可以帮助模型在读到外层步骤的当下判断内层是否已完成。需要回放时，可在参考图上按序列叠加步号。

下一轮可先复用现有仿真样本及规则程序的标准答案，对照「先复原再判断」和「直接读取坐标序列」两条流程，比较合规结论和首次违规定位。现场部分待用实际图像核对布局提取和坐标一致性。 [现有实验方案](experiment-plan.md)
